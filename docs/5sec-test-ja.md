# ドパガキ 5秒テスト（20〜30代の日本人向け）

## 進め方（1人3分）

1. スマホで `https://darkhos.github.io/dopagaki/?lang=ja` を開いた状態で渡す
2. 「5秒だけ画面を見てください」と言い、5秒後にスマホを伏せる
3. 下の3問を口頭で聞き、答えをそのまま記録する（誘導しない）
4. 最後にスマホを返して「気になるところを自由に触ってみてください」と30秒観察する

## 質問

| # | 質問 | 正解・見るポイント |
|---|---|---|
| Q1 | 一番安いのはどこでしたか？ | TOP3の1位（クリニック名、またはおおよその値段）が言えるか |
| Q2 | 日本と比べて、いくらくらいおトクでしたか？ | 「80%くらい」「5万円くらい」など割引率か節約額が出るか |
| Q3 | このページ、友だちにシェアしたいと思いますか？（はい／たぶん／いいえ）その理由は？ | 「はい・たぶん」の割合と理由のことば |
